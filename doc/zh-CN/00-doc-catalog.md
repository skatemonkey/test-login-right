# 文档目录

从这里开始。本目录按阅读顺序组织：

- [01-overview.md](./01-overview.md): 系统环境、架构和目录结构。
- [02-change-context-map.md](./02-change-context-map.md): 面向常见代码修改任务的导航文档。用于说明从哪里开始、通常要看哪些文件，以及如何定位验证入口。不要把强制性编码规则放在这里。
- [engineering-standards/00-eng-std-catalog.md](./engineering-standards/00-eng-std-catalog.md): 规范级、不可随意偏离的工程规则与约定。用于定义什么是允许、要求或禁止的做法。不要把任务级修改入口放在这里。
- [modules/00-module-catalog.md](./modules/00-module-catalog.md): 功能模块、接口与关键入口文件。
