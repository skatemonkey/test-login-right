# Documentation Catalog

Start here. This folder is organized in reading order:

- [01-overview.md](./01-overview.md): system environment, architecture, and file structure.
- [02-change-context-map.md](./02-change-context-map.md): task-oriented navigation for common code changes. Use it to find where to start, which files usually matter, and what to verify. Do not put mandatory coding rules here.
- [engineering-standards/00-eng-std-catalog.md](./engineering-standards/00-eng-std-catalog.md): canonical engineering rules and non-negotiable conventions. Use it to define what is allowed, required, or forbidden. Do not put task-specific change entry points here.
- [modules/00-module-catalog.md](./modules/00-module-catalog.md): feature modules, endpoints, and key entry files.
